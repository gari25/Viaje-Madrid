# ViajeX · Europa 2026

Itinerario de consulta para Kateryn y Mariangel, del 3 al 14 de noviembre de 2026.

**Objetivo:** comparar planes A, B y C, revisar rutas, excursiones, mapas y presupuestos. La página es de **solo lectura**: Kateryn solicita cambios desde ChatGPT, se actualizan los archivos de este repositorio y Cloudflare los publica al conectarlo.

## Publicación gratuita con Cloudflare Pages
1. En Cloudflare, ir a **Workers & Pages → Create application → Pages → Connect to Git**.
2. Conectar **gari25/Viaje-Madrid**, rama **main**.
3. Sin framework, sin comando de compilación, directorio raíz `/` o `.`.
4. Desplegar y compartir el nuevo enlace `pages.dev` con Mariangel.
5. Al modificar `index.html` en `main`, Cloudflare publicará los cambios automáticamente.

**Nota:** si la página anterior fue creada con *Direct Upload*, es necesario crear otro proyecto Pages con integración Git; el proyecto anterior no se convierte directamente.
